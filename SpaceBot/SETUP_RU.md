# Быстрый старт в Visual Studio 2019

1. Создай пустой репозиторий на GitHub (например, `spacebot-csharp`).
2. Скопируй папку `SpaceBot` в локальную папку репозитория.
3. В VS2019 открой `src/SpaceBot.App/SpaceBot.App.csproj`.
4. Установи NuGet-пакеты (следующий шаг):
   - OpenCvSharp4
   - OpenCvSharp4.runtime.win
   - Serilog

## Что уже реализовано в каркасе
- Доменные модели цели/координат.
- Выбор цели по минимальной дистанции без приоритета типа.
- FSM-скелет с фиксацией текущей цели до сбора.
- Простейшая WinForms-оболочка для запуска/остановки цикла.
